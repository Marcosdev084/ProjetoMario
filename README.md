🍄 Projeto Mario

Este projeto é uma página web inspirada no universo do Super Mario, desenvolvida com foco na prática de HTML, CSS e JavaScript.

O objetivo foi aplicar conceitos fundamentais do desenvolvimento web, criando uma interface visual interativa e responsiva.

🚀 Tecnologias Utilizadas

HTML5

CSS3

JavaScript

Git e GitHub

🎯 Objetivos do Projeto

Este projeto foi desenvolvido com fins educacionais, buscando consolidar conhecimentos em desenvolvimento front-end e boas práticas de organização de código.

Durante o desenvolvimento foram explorados conceitos importantes utilizados no dia a dia de desenvolvedores web.

📚 Aprendizados

Ao desenvolver este projeto, foi possível praticar e aprender diversos conceitos, como:

🎨 Estilização com CSS

Uso de CSS para layout e estilização

Aplicação de cores, fontes e espaçamentos

Organização de estilos em arquivos separados

Uso de hover effects e elementos visuais

📱 Responsividade

Criação de layouts adaptáveis para diferentes telas

Uso de media queries

Ajustes de elementos para melhor visualização em dispositivos móveis

⚡ Interatividade com JavaScript

Manipulação de elementos do DOM

Criação de animações e efeitos visuais

Controle de eventos do usuário

🧠 Organização de Projeto

Separação de arquivos:

HTML

🌐 Versionamento com Git

Uso de Git para controle de versão
